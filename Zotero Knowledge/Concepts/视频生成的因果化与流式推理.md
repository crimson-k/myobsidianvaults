# 视频生成的因果化与流式推理

这一组研究如何把视频生成改造成低延迟、连续输出的过程。DiCoDe 使用压缩 token 的自回归语言模型，LanDiff 结合语义 token 与扩散渲染；CausVid、Causal Forcing 系列和 Causal-rCM 关注自回归扩散及少步蒸馏。SCD 进一步将时间推理与去噪渲染分离。

## 比较与阅读路径

区分三个轴：跨帧的生成顺序、每帧的去噪步数、训练时使用真实历史还是模型历史。时间因果注意力不等于反事实推理。
